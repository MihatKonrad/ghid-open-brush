# Controlerele în Open Brush

Quest 3S are două controlere, stâng și drept. În Open Brush, unul devine **pensula**, celălalt **paleta**. Tabelul de mai jos e pentru **dreptaci** (implicit).

## Mâna-pensulă (dreapta)

| Buton | Ce face în Open Brush |
| --- | --- |
| **Trăgaci** (*trigger*, sub degetul arătător) | desenează; apasă butoanele de pe paletă; activează unealta curentă |
| **Buton lateral** (*grip*, sub degetul mijlociu) | apucă: lumea, un panou, o imagine, o selecție, oglinda |
| **Joystick** stânga/dreapta | grosimea pensulei; la cameră, schimbă modul |
| ++a++ | în selecție: comută selectare/deselectare; ținut apăsat, copiază |
| ++b++ | meniul rapid (*Quick Tools*) |
| **Meta** | meniul căștii; ținut apăsat, recentrează imaginea |

## Mâna-paletă (stânga)

| Buton | Ce face în Open Brush |
| --- | --- |
| **Joystick** stânga/dreapta | rotește paleta (Tools / Brushes / Color) |
| ++x++ | anulează (*Undo*); ținut apăsat, anulează mai mulți pași |
| ++y++ | refă (*Redo*) |
| **Buton lateral** (*grip*) | împreună cu cel din dreapta: mută, rotește, scalează lumea |
| **Trăgaci** | ținut apăsat la selectare/ștergere: filtrează după pensulă; ținut + butonul cu iepure/țestoasă: *Lazy Input* |

!!! tip "Indicii pe controlere"
    La prima folosire, Open Brush arată etichete lângă butoanele controlerelor. Dacă le-ai pierdut, **Admin Panel → ⋯ → Tutorial** le aduce înapoi.

## Stângaci { #stangaci }

Două variante:

- **rapid:** lovește ușor una de alta **bazele** celor două controlere. Pensula și paleta își schimbă mâna;
- **permanent:** **Admin Panel → ⋯ → Settings → Swap Hands**. Alegerea se păstrează între sesiuni.

După schimbare, butoanele își păstrează funcțiile, dar pe controlerul celălalt: anularea devine ++a++, refacerea ++b++.

## Curelușa de la încheietură

Fiecare controler are o curelușă. **Purtați-o mereu pe încheietură**: în VR, mâinile se mișcă larg și un controler scăpat poate lovi pe cineva sau se poate sparge.

## Baterii

Fiecare controler folosește o baterie AA. Capacul se deschide prin glisare, pe partea mânerului. Avertismentul de baterie descărcată apare în cască.
