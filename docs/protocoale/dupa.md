# După sesiune

## Lista de închidere

- [ ] fiecare schiță **salvată**, cu numele corect;
- [ ] capturile pentru portofoliu făcute, dacă e sfârșit de etapă (vezi [Fac imagini pentru portofoliu](../procese/capturi.md));
- [ ] Open Brush închis, căștile în repaus;
- [ ] **curățare**: pernițele cu șervețele fără alcool, lentilele cu laveta uscată (vezi [Igienă și siguranță](igiena-siguranta.md));
- [ ] **încărcare**: bateriile B100 și căștile sub 50%;
- [ ] **depozitare**: în trusă, cu lentilele protejate, departe de soare;
- [ ] **fișa sesiunii** completată.

## Fișa sesiunii { #fisa-sesiunii }

O fișă scurtă pe sesiune, pe hârtie sau într-un tabel comun:

| Câmp | Exemplu |
| --- | --- |
| data | 3 noiembrie 2026 |
| profesor | — |
| grupa / elevii prezenți | G1: 4 elevi |
| casca | C1 |
| fișierul schiței | `G1_spatiu_2026-11-03` |
| ce s-a lucrat | scheletul spațiului, peretele de est |
| incidente / disconfort | — |
| probleme tehnice | controlerul stâng a rămas fără baterie |
| pentru data viitoare | lumini și ceață |

!!! tip "Pentru raportare"
    Fișele sesiunilor documentează și activitatea din proiect. Păstrați-le la un loc, împreună cu capturile.
