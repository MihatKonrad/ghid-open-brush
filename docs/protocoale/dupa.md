# După sesiune

- [ ] fiecare schiță **salvată**, cu numele corect (vezi [Redenumește o schiță nouă](../open-brush/salvare.md#redenumeste));
- [ ] **igienizare** cu șervețel umed a părților care ating fața și capul; **lentilele nu se șterg cu șervețelul umed**, doar cu laveta din microfibră uscată (vezi [Igienă și siguranță](igiena-siguranta.md));
- [ ] **încărcare**: la finalul tuturor sesiunilor se pun la încărcat **toate bateriile** (căștile și bateriile B100 ale curelelor), ca la următoarea sesiune să fie sigur încărcate;
- [ ] **depozitare**: cu lentilele protejate, departe de soare.
