# Selecție (*Selection*)

<div class="pe-scurt" markdown>**Pe scurt:** alegi mai multe linii sau obiecte și le muți, le copiezi, le grupezi sau le ștergi împreună. · **Mod:** doar Advanced · **Unde:** fața *Tools* sau meniul rapid ++b++</div>

## Selectează

1. Alege **Selection**.
2. Ține trăgaciul și treci cu vârful controlerului prin liniile dorite. Liniile selectate se evidențiază.
3. Ca să **scoți** linii din selecție, apasă ++a++ pe mâna-pensulă (comută în modul de deselectare) și treci prin ele. Apasă ++a++ din nou ca să revii la selectare.

!!! tip "Selectează doar o pensulă"
    Ține apăsat **trăgaciul mâinii-paletă** când atingi prima linie. Selecția ia apoi doar liniile făcute cu aceeași pensulă.

## Ce faci cu selecția

| Vreau să… | Fac |
| --- | --- |
| **mut** selecția | o apuc cu butonul lateral și o mut |
| **rotesc / scalez** selecția | o apuc cu ambele butoane laterale |
| **copiez** selecția | țin ++a++ în timp ce controlerul atinge selecția: apare o copie ușor decalată. Sau țin ++a++ în timp ce o mut: copia rămâne exact în locul inițial |
| **șterg** selecția | o apuc și o arunc |
| **grupez** liniile | butonul de grupare din opțiunile selecției: se vor mișca împreună și data viitoare. Apăsat din nou, desface grupul |
| **selectez tot** | țin apăsat pe *Selection* → **Select All** |
| **inversez** selecția | țin apăsat pe *Selection* → **Invert Selection** |
| **mut pe alt strat** | fac activ stratul dorit și aleg **Move Selection to Current Layer** (vezi [Straturi](../straturi.md)) |
| **repictez** tot ce e selectat | vezi [Repictare](repictare.md#mai-multe-linii-deodata) |

!!! warning "Selecții mari pe Quest"
    *Select All* și *Invert* pe un desen foarte încărcat pot bloca scurt casca. Așteaptă câteva secunde înainte să apeși din nou.

## Când o folosești

- muți un element mai încolo, fără să-l redesenezi;
- repeți un motiv (o fereastră, un copac, o piatră) prin copiere;
- grupezi o parte a spațiului ca să o poți muta întreagă;
- salvezi o bucată ca să o refolosești în alt desen (vezi [Imagini și modele](../import.md#refoloseste-linii-salvate)).
