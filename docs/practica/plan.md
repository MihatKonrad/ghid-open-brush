# Plan pe săptămâni

O propunere pentru un an școlar cu **2 ore pe săptămână**, plus câteva săptămâni intensive cu facilitatorii. Adaptați-o după ritmul grupei.

!!! info "Exemplul proiectului *Spații pentru sine*"
    Atelierele merg din **2 noiembrie 2026 până în 4 iunie 2027** (27 de săptămâni de lucru, fără vacanțe). Facilitatorii sunt prezenți la școală în **2-5 noiembrie**, **25-26 noiembrie**, o săptămână în **martie** și o săptămână în **mai**. În celelalte săptămâni, profesorul ține cele 2 ore săptămânale.

## Etapa 1: obișnuirea cu instrumentul (noiembrie–decembrie)

| Săptămâna | Ce | Exerciții |
| --- | --- | --- |
| atelier intensiv (facilitatori) | prima întâlnire cu casca, protocoale, Start rapid | E1, E2, E3 |
| 2–3 | linie, gest, pensule | E3, E4 |
| atelier intensiv (facilitatori) | volum, scară, simetrie | E5, E6 |
| 5–7 | consolidare; trecerea în Advanced | E7, E8 |

**Rezultat:** fiecare elev se descurcă singur în cască și salvează corect.

## Etapa 2: atmosferă și limbaj propriu (ianuarie–februarie)

| Săptămâna | Ce | Exerciții |
| --- | --- | --- |
| 8–9 | culoare, variație, atmosferă | E8, E9 |
| 10–11 | pragul, spațiul la scara corpului | E10 |
| 12–13 | colțul meu (individual) | E11 |
| 14 | prezentare internă: fiecare își arată colțul | — |

**Rezultat:** fiecare elev are un mic spațiu propriu și un set de capturi.

## Etapa 3: spațiul grupului (martie–aprilie)

| Săptămâna | Ce |
| --- | --- |
| atelier intensiv (facilitatori) | formarea grupelor, cele trei cuvinte, schițe pe hârtie, scheletul spațiului |
| următoarele 5–6 | construcție pe straturi, pe rând în cască (rețeta [spațiului personalizat](../procese/spatiu-personalizat.md)) |
| 1 săptămână | revizuire: fiecare grupă intră în spațiul celeilalte și dă feedback |

## Etapa 4: finalizare (mai–iunie)

| Săptămâna | Ce |
| --- | --- |
| 1–2 | finisare: lumini, ceață, accente; ascunderea straturilor de construcție |
| atelier intensiv (facilitatori) | pregătirea prezentării: capturi finale, panorame 360°, export |
| ultimele | arhivare completă (vezi [Salvare și arhivare](../protocoale/arhivare.md)) și pregătirea expoziției |

!!! tip "Ce documentați pe parcurs"
    La sfârșitul fiecărei etape: capturile de portofoliu ale fiecărei grupe și fișele sesiunilor. Așa se vede evoluția și aveți materialul gata pentru expoziție și raportare.
